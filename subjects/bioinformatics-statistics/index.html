Bioinformatics and statistics

File formats, alignment, assembly, variant calling, workflows and reproducibility, together with the statistical ideas needed to interpret genomic results honestly.

42 entries. Open these in the searchable dictionary.

  • Association versus causation

    An association means two things vary together: a genetic variant is seen more often in people with a trait, or a gene's expression tracks a disease state. A causal relationship means that changing one would change the other. Association is observed; causation is inferred, and the inference requires evidence beyond the observation that the two travel together.

    Bioinformatics and statistics Human and population genomics Published

  • Basic Local Alignment Search Tool (BLAST)

    The Basic Local Alignment Search Tool, abbreviated BLAST, searches a query sequence against a database and returns the entries that resemble it most, together with a measure of how surprising each match is. It is the usual first question asked of an unknown sequence: what else looks like this, and how closely? Variants of the tool handle nucleotide and protein queries.

    Bioinformatics and statistics Pathogen genomics Published

  • Batch effect

    A batch effect is a systematic technical difference between groups of samples that were processed separately. Samples extracted on different days, sequenced on different instruments, or prepared by different staff can differ measurably for reasons that have nothing to do with biology. If those technical groupings line up with the comparison of interest, the artefact is indistinguishable from the biological signal.

    Bioinformatics and statistics Published

  • Bioinformatics

    Bioinformatics is the discipline that stores, organises and analyses biological data using computers. Most of that data comes from sequencing DNA, RNA or protein, and it arrives in volumes far too large to inspect by hand. Bioinformatics supplies the file formats, databases, algorithms and statistics that turn raw instrument output into results a biologist, clinician or public health team can actually read and act upon.

    Bioinformatics and statistics Published

  • Computational reproducibility

    Computational reproducibility means that someone else, given the same data and the same description of the analysis, obtains the same results. It is a weaker and more achievable goal than replication, which asks whether a finding holds in a new experiment with new samples. Reproducibility is about the transparency of the computation, not about whether the conclusion is true.

    Bioinformatics and statistics Ethics and data governance Published

  • Confidence interval (CI)

    A confidence interval is a range of values, calculated from the data, that expresses how precisely a quantity has been estimated. A ninety-five per cent interval is constructed by a procedure that, repeated across many studies, would contain the true value in ninety-five per cent of them. A wide interval signals an imprecise estimate; a narrow one signals a precise estimate.

    Bioinformatics and statistics Published

  • Containerisation

    Containerisation packages a piece of software together with the libraries and settings it needs, so that it runs the same way on any machine with a compatible container runtime. In bioinformatics it solves a persistent problem: analyses depend on long chains of tools and libraries whose versions differ between computers, and those differences quietly change results.

    Bioinformatics and statistics Published

  • De novo assembly

    De novo assembly reconstructs a genome from sequencing reads alone, without using a reference sequence of the same organism as a guide. It is the approach taken when no suitable reference exists, when the sample may contain sequence the reference lacks, or when the aim is to describe structure rather than catalogue differences from a template.

    Bioinformatics and statistics Pathogen genomics Published

  • Differential expression

    Differential expression analysis asks which genes or transcripts are expressed at different levels between conditions, such as treated and untreated cells, or tumour and adjacent tissue. It compares normalised measurements across replicate samples, estimates how much each feature changes, and assesses whether the change is larger than the variability seen between replicates of the same condition.

    Bioinformatics and statistics Published

  • Effective population size (Ne)

    Effective population size, written Ne, is the size of an idealised population that would lose genetic variation at the same rate as the real population being studied. It is usually much smaller than the number of people alive, because real populations have unequal family sizes, overlapping generations and uneven sex ratios. It is a bookkeeping device for predicting drift, not a headcount.

    Human and population genomics Bioinformatics and statistics Published

  • FASTA format

    FASTA is a plain-text format for storing sequences. Each record begins with a header line starting with a greater-than sign, followed by the sequence itself on the lines beneath. It is used for reference genomes, gene and protein sequences, assemblies and consensus sequences. Unlike FASTQ, a FASTA record carries no quality information, only the letters of the sequence.

    Bioinformatics and statistics Published

  • FASTQ format

    FASTQ is the standard text format for raw sequencing reads. Each read occupies four lines: an identifier, the sequence of bases, a separator, and a string of characters encoding how confident the instrument was about each base. Because the quality string travels with the sequence, downstream software can trim or discard unreliable positions rather than treating every base as equally trustworthy.

    Bioinformatics and statistics Sequencing and laboratory methods Published

  • False discovery rate (FDR)

    The false discovery rate, abbreviated FDR, is the expected proportion of mistakes among the results a study declares positive. If a list of one hundred differentially expressed genes is reported at a five per cent false discovery rate, about five of them are expected to be false findings. It describes the quality of a list rather than the status of any single item.

    Bioinformatics and statistics Published

  • GFF and GTF formats

    GFF and GTF are text formats that describe where features sit on a genome. Each line gives a sequence name, a start and end coordinate, a feature type such as gene, transcript or exon, a strand, and a set of attributes. They are how a genome assembly, which is only a string of letters, is linked to the biology layered on top of it.

    Bioinformatics and statistics Published

  • Genome assembly

    Genome assembly is the process of reconstructing the long chromosomes of an organism from the many short or medium-length reads a sequencer produces. Overlapping reads are joined into longer stretches called contigs, which may then be ordered and oriented into scaffolds. The output is a set of sequences that approximates the genome, together with statistics describing how complete and contiguous it is.

    Bioinformatics and statistics Published

  • Genome-wide association study (GWAS)

    A genome-wide association study, or GWAS, tests hundreds of thousands to millions of positions across the genome to see whether any version of a position occurs more often in people with a trait than in people without it. It scans the genome without a prior hypothesis about which gene matters, and it reports statistical associations rather than proven causes.

    Human and population genomics Bioinformatics and statistics Published

  • Genotype imputation

    Genotype imputation fills in positions that were not directly measured, by comparing the positions that were measured against a reference panel of people whose genomes are known in detail. Because nearby variants travel together on shared stretches of chromosome, matching those stretches lets software predict the missing genotypes, together with a confidence value for each prediction.

    Human and population genomics Bioinformatics and statistics Published

  • Haplotype phasing

    Haplotype phasing works out which of a person's genetic variants sit on the same copy of a chromosome. Standard genotyping records that someone carries two different versions at two positions, but not how those versions are paired between the maternal and paternal copies. Phasing resolves that arrangement, either by statistical comparison with known haplotypes or by reading long DNA molecules directly.

    Human and population genomics Bioinformatics and statistics Published

  • Hardy-Weinberg equilibrium (HWE)

    Hardy-Weinberg equilibrium describes the simple relationship expected between how often each allele occurs and how often each genotype occurs, in a large population that mates at random and in which nothing is disturbing the alleles. If the two alleles have frequencies p and q, the expected genotype proportions are p squared, two pq and q squared. Real populations only approximate this, so it serves as a baseline for comparison.

    Human and population genomics Bioinformatics and statistics Published

  • Heritability

    Heritability is the share of the differences between people in a trait, within a particular population and set of environments, that can be attributed to differences in their genes. It is a property of a group rather than of an individual, and it changes when the population or the environment changes. A high value does not mean a trait is fixed or beyond modification.

    Human and population genomics Bioinformatics and statistics Published

  • Linkage disequilibrium (LD)

    Linkage disequilibrium, or LD, means that particular versions of two nearby DNA positions turn up together more often than chance alone would predict. It arises because stretches of chromosome are passed down intact, and recombination only occasionally shuffles them. LD generally weakens with distance along the chromosome and with the number of generations since the alleles first appeared together.

    Human and population genomics Bioinformatics and statistics Published

  • Machine learning in genomics

    Machine learning covers methods that learn patterns from data rather than following rules written by a programmer. In genomics it is used to predict regulatory elements, classify tumours from molecular profiles, call variants, assign taxonomy to sequences and predict protein structure. A model is trained on examples with known answers, then evaluated on data it has never seen.

    Bioinformatics and statistics Published

  • Minor allele frequency (MAF)

    Minor allele frequency, or MAF, is how often the less common of two versions of a DNA position is seen in a group of people. If eight in every hundred copies of a position carry a G and ninety-two carry an A, the minor allele frequency is 0.08. The figure describes a sampled population, not an individual, and the same allele can be common in one population and almost absent in another.

    Human and population genomics Bioinformatics and statistics Published

  • Multiple testing correction

    Multiple testing correction adjusts statistical results when many hypotheses are tested at once. If a threshold meant for a single test is applied to a million of them, a large number of apparently significant findings will arise purely by chance. Correction either raises the bar for significance or reinterprets the results so that the expected number of false findings is controlled.

    Bioinformatics and statistics Published

  • N50

    N50 is a summary statistic describing how contiguous a genome assembly is. Sort the assembled pieces from longest to shortest and add their lengths until half the total assembly length is reached; the length of the piece that takes the running total past that halfway point is the N50. A larger N50 means the assembly is built from longer pieces.

    Bioinformatics and statistics Published

  • Normalisation

    Normalisation adjusts measurements so that samples can be compared fairly. In sequencing, one sample may simply have produced more reads than another, and longer genes attract more reads than shorter ones. Normalisation removes such technical differences in scale, so that remaining differences between samples are more likely to reflect biology rather than how much data each sample yielded.

    Bioinformatics and statistics Published

  • Odds ratio (OR)

    An odds ratio compares the odds of an outcome between two groups. In genomic association studies it usually compares the odds of a trait in people carrying one allele with the odds in those carrying another. A value of one means no difference, above one means higher odds in the first group, and below one means lower odds. Both directions matter.

    Bioinformatics and statistics Human and population genomics Published

  • Overfitting

    Overfitting happens when a model learns the particular noise of the data it was trained on instead of the pattern that generalises. Such a model performs impressively on its training data and poorly on anything new. It is a constant hazard in genomics, where datasets typically contain far more measured features than samples.

    Bioinformatics and statistics Published

  • P value

    A p-value is the probability of observing data at least as extreme as those collected, if the hypothesis of no effect were true and the statistical model were correct. A small p-value means the data would be surprising under that assumption. It does not give the probability that the hypothesis is true, nor does it measure how large or important an effect is.

    Bioinformatics and statistics Published

  • Pangenome

    A pangenome is a representation of a species' DNA that holds many genomes at once, instead of a single linear sequence. For humans it is assembled from people of diverse ancestries, so that sequence present in some people but missing from the traditional reference is included. It is usually stored as a graph, with shared paths and alternative branches where genomes differ.

    Human and population genomics Bioinformatics and statistics Published

  • Population structure

    Population structure means that the people in a dataset are not one randomly mixing group: allele frequencies differ systematically between subgroups because of geography, history, migration and patterns of partnership. If this patterning is ignored, it can create apparent links between a variant and a trait that actually reflect which subgroup a person belongs to rather than any biological effect.

    Human and population genomics Bioinformatics and statistics Published

  • Positive predictive value (PPV)

    Positive predictive value, abbreviated PPV, is the proportion of positive test results that are correct. It answers the question a person actually asks: given that my result is positive, how likely is it that the condition is really present? Unlike sensitivity and specificity, it depends strongly on how common the condition is in the group being tested.

    Bioinformatics and statistics Clinical and cancer genomics Published

  • Read mapping

    Read mapping is the process of finding, for each short sequencing read, the place in a reference genome it most likely came from. Millions of reads are placed in this way, producing a pile of overlapping reads at every covered position. Everything that follows, including variant calling and expression counting, depends on those placements being broadly correct.

    Bioinformatics and statistics Published

  • Reference genome

    A reference genome is an agreed, assembled DNA sequence used as a shared coordinate system, so that laboratories everywhere can describe positions and variants in the same way. The current human reference is a mosaic built from a small number of donors. It is a convenient yardstick rather than a model of a healthy or typical person, and it does not contain all human variation.

    Human and population genomics Bioinformatics and statistics Published

  • SAM and BAM formats

    SAM and BAM are the standard formats for storing sequencing reads after they have been mapped to a reference genome. SAM is human-readable text; BAM is the same information compressed into a binary file that software can read quickly. Each record says where a read aligned, how well it aligned, and how its bases correspond to the reference at that position.

    Bioinformatics and statistics Published

  • Sensitivity and specificity

    Sensitivity is the proportion of people or samples that truly have a condition and are correctly identified by a test. Specificity is the proportion of those without the condition that the test correctly calls negative. Both are properties of the test measured against a reference standard, and they describe performance in two different groups, so they must be reported together.

    Bioinformatics and statistics Clinical and cancer genomics Published

  • Sequence alignment

    Sequence alignment is the arrangement of two or more sequences so that corresponding positions sit beneath one another, with gaps inserted where one sequence has material the other lacks. It is the basic operation for comparing sequences, and the resulting pattern of matches, mismatches and gaps is the evidence used to infer relatedness, detect variants or identify an unknown sequence.

    Bioinformatics and statistics Published

  • Variant Call Format (VCF)

    Variant Call Format, usually shortened to VCF, is the standard text format for recording differences between sequenced samples and a reference genome. Each line describes one position: where it sits, what the reference carries, what alternative alleles were seen, how confident the caller is, and the genotype of every sample in the file. Annotations and filters are added as extra fields.

    Bioinformatics and statistics Clinical and cancer genomics Published

  • Variant annotation

    Variant annotation adds meaning to a list of genomic positions. For each variant it records which genes and transcripts it falls in, what effect it is predicted to have on the protein, how often the allele is seen in population databases, and what clinical databases already say about it. Annotation organises the evidence; it does not by itself decide significance.

    Bioinformatics and statistics Clinical and cancer genomics Published

  • Variant calling

    Variant calling is the step that decides, from the reads piled up at each position of a genome, whether a sample differs from the reference and what its genotype is. The caller weighs the number of reads supporting each allele, their base and mapping qualities, and the expected behaviour of the sequencing technology, then emits the sites it judges to be real.

    Bioinformatics and statistics Clinical and cancer genomics Published

  • Version control

    Version control is a system that records the history of a set of files, who changed what, when and why. Each saved state can be recovered, differences between states can be inspected, and parallel lines of work can be developed and then merged. In genomics it is applied to analysis code, workflow descriptions, configuration and documentation.

    Bioinformatics and statistics Published

  • Workflow manager

    A workflow manager is software that describes an analysis as a set of steps with declared inputs and outputs, then runs those steps in the right order, in parallel where possible, on a laptop, a cluster or in the cloud. It keeps track of what has already completed, so an interrupted run can resume rather than start again from the beginning.

    Bioinformatics and statistics Published
