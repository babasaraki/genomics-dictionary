GFF and GTF formats

Bioinformatics and statistics Published

Definition

GFF and GTF are text formats that describe where features sit on a genome. Each line gives a sequence name, a start and end coordinate, a feature type such as gene, transcript or exon, a strand, and a set of attributes. They are how a genome assembly, which is only a string of letters, is linked to the biology layered on top of it.

Technical explanation

General Feature Format and its stricter relative Gene Transfer Format both use nine tab-separated columns, differing mainly in how the final attribute column is written. Coordinates are one-based and inclusive, which distinguishes them from BED, a simpler three-to-twelve-column format whose coordinates are zero-based and half-open; converting between the two without adjusting the start coordinate is a standard off-by-one error. Hierarchy is expressed by identifier and parent attributes, so exons point to transcripts and transcripts to genes, allowing alternative isoforms to coexist. Annotation files drive read counting, splice-aware alignment, variant consequence prediction and genome browser displays. Their chief limitation is that annotation is a model, not an observation: gene models differ between Ensembl, RefSeq and project-specific sets, they are revised with every release, and counts or consequences computed against one version are not strictly comparable with another. Contig naming must also match the reference FASTA exactly, since a mixture of naming conventions is a frequent cause of silently empty results.

Practical example

An RNA sequencing analysis returns almost no assigned reads despite good alignment rates. The reference FASTA uses names such as chr1 while the GTF uses 1, so no feature overlaps any read. Switching to an annotation release matched to the same genome build and naming convention restores the expected counts.

Common misunderstanding

Genome annotation is often read as a settled fact, so that a gene either exists at a locus or does not. Annotation sets are curated models that disagree with one another and change between releases, particularly for non-coding transcripts and alternative isoforms. Reporting the exact annotation source and version is therefore part of reporting the result.
