Pango lineage

Pathogen genomics Published

Definition

A Pango lineage is a label from a naming system used to describe fine-grained groups of SARS-CoV-2 genomes that share recent common ancestry. Names such as B.1.1.7 or BA.2 use letters and dots to show how groups branch from one another. The system was designed so that newly spreading groups can be named quickly during an epidemic.

Technical explanation

The Pango nomenclature assigns hierarchical alphanumeric labels to SARS-CoV-2 lineages that represent epidemiologically relevant groups, typically those associated with an introduction into a new region or with notable growth. A new lineage is defined by a set of characteristic nucleotide changes and a supported position on the global phylogeny, and descendant lineages extend the parent label with an additional numeric level. Because label depth is capped, long chains are aliased with new letter prefixes, which is why BA.2 is a descendant of B.1.1.529 rather than of B. Assignment of a query genome is performed computationally against a curated set of reference genomes and definitions, and designations are curated by a committee as new data accumulate. The system is dynamic: lineages can be designated, renamed through aliasing or withdrawn, so an assignment carries a tool and version. Assignment quality degrades with incomplete genomes, since masked positions remove the defining changes, and a lineage label describes ancestry rather than any phenotype such as transmissibility or severity.

Practical example

A surveillance team reprocesses last season's genomes with an updated version of the assignment software. Several sequences previously reported as an older parent lineage now receive a more specific descendant label, because that descendant had not yet been designated when the genomes were first analysed. The team records the software and definition versions in its reports so that counts across months remain interpretable.

Common misunderstanding

A frequent misunderstanding is that a Pango label implies clinical or transmission properties. It does not. The label records a position in a genealogy inferred from sequence data. Any claim that a lineage spreads faster or causes more severe illness requires separate epidemiological and clinical study; the name itself conveys ancestry, not risk.
