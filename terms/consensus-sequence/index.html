Consensus sequence

Pathogen genomics Published

Definition

A consensus sequence is a single representative sequence built from many overlapping sequencing reads covering the same part of a genome. At each position the base seen in most reads is chosen, and positions with too little data are usually masked with the letter N. For pathogens, the consensus genome is the file that is shared, compared and used to assign a lineage.

Technical explanation

A consensus sequence is produced by aligning reads to a reference or to a de novo assembly and then calling, for each position, the most frequent base among reads passing quality filters. Tools apply minimum depth and allele-frequency rules: positions below a depth threshold are masked as N, and a variant base is fixed in the consensus only if it exceeds a defined frequency, commonly a clear majority. The result is a haploid-style summary of a population of genomes, which is convenient for lineage assignment and phylogenetics but discards within-host diversity, including minority variants that may matter for resistance or immune escape. Ambiguity codes can be used where a site is genuinely mixed. Consensus genomes are sensitive to method: different depth cut-offs, primer trimming settings and reference choices produce different numbers of masked positions, and amplicon dropout caused by primer-site variants creates systematic gaps that can be mistaken for deletions. Reporting the pipeline, reference accession and masking rules alongside the sequence is therefore part of good practice.

Practical example

A laboratory generates SARS-CoV-2 genomes by tiled amplicon sequencing. One batch shows a long run of N characters in the spike region. Rather than reporting a deletion, the bioinformatician checks coverage, finds that a single amplicon failed across the batch, and traces it to a variant under a primer binding site. The affected genomes are flagged and the primer scheme is updated.

Common misunderstanding

Many readers treat a consensus genome as the genome of the infecting pathogen. It is a summary of whatever mixture was sampled and sequenced, produced under specific thresholds. Minority variants are invisible in it, mixed infections may be collapsed into one sequence, and masked regions reflect coverage rather than biology. Comparisons are only fair between genomes made the same way.
