Multiple testing correction

Bioinformatics and statistics Published

Definition

Multiple testing correction adjusts statistical results when many hypotheses are tested at once. If a threshold meant for a single test is applied to a million of them, a large number of apparently significant findings will arise purely by chance. Correction either raises the bar for significance or reinterprets the results so that the expected number of false findings is controlled.

Technical explanation

Two broad aims exist. Family-wise error rate control limits the probability of even one false positive across the whole set; the Bonferroni adjustment, dividing the threshold by the number of tests, is the simplest and most conservative instance, and the genome-wide significance threshold conventionally used in association studies derives from this logic applied to the number of effectively independent common variants. False discovery rate control instead limits the expected proportion of false positives among the findings declared significant, which is far more powerful when thousands of true effects are plausible, as in expression analysis. The choice is a scientific one: family-wise control suits a setting where a single false claim is costly, false discovery rate control suits screening where a ranked candidate list will be followed up. Correction assumes the tests were specified before looking at the data; applying it after selecting promising comparisons, or correcting only within a subset while reporting across many subsets, understates the true multiplicity. Correlation between tests, as from linkage disequilibrium or co-expression, makes simple corrections conservative.

Practical example

A differential expression analysis of twenty thousand genes returns nine hundred genes with an uncorrected p-value below 0.05, when about a thousand would be expected by chance alone if nothing were differentially expressed. After false discovery rate adjustment, forty genes remain below a five per cent threshold, and these form the shortlist taken forward for validation.

Common misunderstanding

Correction is often seen as a statistical penalty that hides real findings. It does not remove true signal; it calibrates the claim being made, so that a list of results carries a stated error rate. The genuine problem is the opposite habit: testing many hypotheses, reporting the striking ones, and correcting for only those that were reported.
