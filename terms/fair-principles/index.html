FAIR principles

Ethics and data governance Published

Definition

The FAIR principles are a set of guidelines stating that research data should be findable, accessible, interoperable and reusable. They describe how data and their descriptions should be organised so that both people and computers can locate and use them. FAIR concerns good data management; it does not mean data must be open to everyone.

Technical explanation

The FAIR principles specify properties of data and metadata rather than a technology. Findable requires a globally unique and persistent identifier, rich metadata and indexing in a searchable resource. Accessible requires a standardised, open protocol for retrieval, with authentication where needed, and that metadata remain available even if the data themselves are withdrawn. Interoperable requires formal, shared vocabularies and ontologies, and qualified references between datasets. Reusable requires detailed provenance, community standards and a clear usage licence. In genomics this translates into practices that are already partly established: accessioning in public archives, controlled vocabularies for sample and phenotype description, standard file formats, and machine-readable data use conditions that allow automated matching of requests to permitted uses. The principles are deliberately compatible with controlled access, since accessibility refers to a clearly specified procedure rather than unrestricted download. Limitations are recognised: FAIR says nothing about data quality, about equity in who benefits from reuse, or about the rights of the communities from whom data originate, which is why complementary principles emphasising collective interests and sovereignty have been proposed alongside it.

Practical example

A laboratory depositing sequence data registers each sample with a persistent accession, describes collection date, location and host using controlled vocabularies, records the pipeline version used, and attaches a licence and data use conditions. A later meta-analysis can then select relevant records automatically rather than contacting the laboratory to interpret free-text fields.

Common misunderstanding

FAIR is frequently read as a synonym for open data. The principles govern how data are described and how access is arranged, not whether access is unrestricted; sensitive human data can be FAIR and still require approval. A further misreading is that depositing a file makes data FAIR, when the work lies almost entirely in the metadata.
