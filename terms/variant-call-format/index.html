Variant Call Format

VCF

Bioinformatics and statistics Clinical and cancer genomics Published

Definition

Variant Call Format, usually shortened to VCF, is the standard text format for recording differences between sequenced samples and a reference genome. Each line describes one position: where it sits, what the reference carries, what alternative alleles were seen, how confident the caller is, and the genotype of every sample in the file. Annotations and filters are added as extra fields.

Technical explanation

A VCF file has a header of metadata lines defining the reference build, the contigs, and every INFO, FILTER and FORMAT field used, followed by one data line per variant site. Mandatory columns give chromosome, position, identifier, reference and alternative alleles, a quality score, a filter status and a semicolon-separated INFO field; per-sample columns then carry genotype, depth, allele depth and genotype quality under keys declared in FORMAT. Multi-sample VCFs from joint calling allow allele frequencies to be computed across a cohort. BCF is the compressed binary equivalent, and compressed, indexed files permit random access by region. Two cautions matter in practice. The absence of a line does not mean a position matches the reference; it may mean no data were available, which is why a genomic VCF with reference blocks is needed to distinguish a confident reference call from a gap. And representation is not unique: the same insertion or deletion can be written at different positions, so files must be normalised and left-aligned before comparison or merging.

Practical example

A laboratory compares variant calls for the same sample produced by two pipelines and finds hundreds of apparent discrepancies. After normalising both VCF files, left-aligning indels and restricting the comparison to regions with adequate coverage in both, nearly all the differences disappear; the remainder sit in a repetitive region where mapping is unreliable.

Common misunderstanding

Users often assume that a position missing from a VCF has been shown to match the reference. It has not. Standard VCF reports only sites where a variant was called, so an absent position may simply have had no coverage or failed a filter, which is a crucial distinction when a negative result will be reported.
