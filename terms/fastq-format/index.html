FASTQ format

Bioinformatics and statistics Sequencing and laboratory methods Published

Definition

FASTQ is the standard text format for raw sequencing reads. Each read occupies four lines: an identifier, the sequence of bases, a separator, and a string of characters encoding how confident the instrument was about each base. Because the quality string travels with the sequence, downstream software can trim or discard unreliable positions rather than treating every base as equally trustworthy.

Technical explanation

A FASTQ record pairs a nucleotide sequence with a per-base quality string of identical length. Each quality character encodes a Phred score as an ASCII character offset by 33 in the encoding now used universally, where the score is minus ten times the logarithm of the estimated probability that the base call is wrong. Files are usually distributed compressed with gzip and are frequently paired, with forward and reverse reads of the same fragment held in matched files in identical order. Public archives distribute submissions in or convert them to this format, so it is the usual entry point to any analysis. Typical first steps are summarising quality by cycle, removing adapter sequence and trimming low-quality tails before alignment or assembly. The main limitations are size and ambiguity: FASTQ files for a human genome run to tens of gigabytes even compressed, and the format carries no structured metadata about the sample, the library or the instrument, so provenance has to be tracked separately. Quality scores are also instrument estimates, not measurements, and can be miscalibrated.

Practical example

Before analysing a batch of SARS-CoV-2 amplicon runs, a surveillance team runs a quality report across all the FASTQ files. One sample shows a sharp drop in quality after cycle 180 and a high proportion of adapter sequence, pointing to a short insert size in that library. The team trims the reads, notes the issue, and flags the sample for a repeat if coverage proves inadequate.

Common misunderstanding

It is tempting to read a FASTQ file as the sample's sequence. It is not: it is a pile of short, redundant, error-containing observations in no particular order, most of which overlap. The consensus or genotype only appears after mapping or assembly, and a base seen in a single read is evidence of very little on its own.
