Basic Local Alignment Search Tool

BLAST

Bioinformatics and statistics Pathogen genomics Published

Definition

The Basic Local Alignment Search Tool, abbreviated BLAST, searches a query sequence against a database and returns the entries that resemble it most, together with a measure of how surprising each match is. It is the usual first question asked of an unknown sequence: what else looks like this, and how closely? Variants of the tool handle nucleotide and protein queries.

Technical explanation

BLAST uses a seed-and-extend heuristic. The query is broken into short words, database entries sharing a word are identified, and those seeds are extended into local alignments that are scored with a substitution matrix. Each hit is reported with a bit score and an expect value, the number of alignments of at least that score expected by chance in a database of that size; the expect value therefore depends on database size and shrinks as databases grow, which is why it is not comparable across searches. Program variants translate the query, the database or both, so that a nucleotide sequence can be compared with protein entries. BLAST is sensitive for divergent homologues but slow against very large collections, so faster tools are preferred for high-throughput screening or metagenomic classification. Three limitations recur: low-complexity regions generate spurious high-scoring hits unless filtered; the best hit is not necessarily the closest relative, especially where databases are unevenly sampled; and a strong match says only that sequences are similar, not that they share function.

Practical example

A laboratory assembles a contig from an environmental sample that no classifier recognises. A translated BLAST search returns moderate matches to phage structural proteins from several hosts. The result is treated as a hypothesis, prompting targeted primer design and confirmation, rather than being recorded as the identity of the organism.

Common misunderstanding

The top BLAST hit is often reported as the identity of the query. It is only the highest-scoring entry in whatever happens to be in the database, and reference collections are heavily skewed towards organisms and regions that have been sequenced most. A high-identity match to a distant relative simply means closer relatives have not been deposited.
