Bioinformatics

Bioinformatics and statistics Published

Definition

Bioinformatics is the discipline that stores, organises and analyses biological data using computers. Most of that data comes from sequencing DNA, RNA or protein, and it arrives in volumes far too large to inspect by hand. Bioinformatics supplies the file formats, databases, algorithms and statistics that turn raw instrument output into results a biologist, clinician or public health team can actually read and act upon.

Technical explanation

Bioinformatics sits between molecular biology, computer science and statistics. A typical project moves raw sequencing reads through quality control, alignment or assembly, feature counting or variant calling, annotation against reference databases, and statistical testing, with each step writing a standardised file that the next step consumes. Practitioners work mostly on the command line under Unix, scripting in Python, R or shell, and increasingly describe whole analyses in a workflow language so that they can be rerun identically. The discipline also builds and curates the public resources the field depends on, including sequence archives, variant databases and genome browsers. Two limitations deserve emphasis. First, a bioinformatics result is only as good as the reference data behind it: reference genomes, annotation sets and variant frequency databases under-represent many populations, and a tool silently inherits those gaps. Second, software versions, parameter choices and reference builds change results, so an analysis that is not version-controlled and documented cannot be trusted to reproduce. Competence therefore includes data management and reproducibility, not only algorithmic skill.

Practical example

A district laboratory sequences twenty Klebsiella pneumoniae isolates from a suspected hospital outbreak. The bioinformatician checks read quality, assembles each genome, screens the assemblies for acquired resistance genes, types the isolates and builds a tree showing which cases cluster together. The laboratory contributes the raw reads and the analysis script to a public archive so that colleagues elsewhere can repeat the work.

Common misunderstanding

Bioinformatics is often treated as a service that begins only after the sequencing is finished, with the analyst handed a folder of files and asked to find something interesting. In practice the analysis plan constrains the experiment: sample numbers, read depth, library type and the handling of batches all have to be settled beforehand, because no algorithm can recover information the design never captured.
