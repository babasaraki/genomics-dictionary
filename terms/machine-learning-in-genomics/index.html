Machine learning in genomics

Bioinformatics and statistics Published

Definition

Machine learning covers methods that learn patterns from data rather than following rules written by a programmer. In genomics it is used to predict regulatory elements, classify tumours from molecular profiles, call variants, assign taxonomy to sequences and predict protein structure. A model is trained on examples with known answers, then evaluated on data it has never seen.

Technical explanation

Approaches range from regularised regression and tree ensembles, which remain strong on tabular data of modest size, to deep neural networks, which learn representations directly from sequence and have proven effective where large labelled datasets exist. Genomic applications pose characteristic difficulties. Datasets have far more features than samples, so regularisation and careful validation are essential. Observations are not independent: variants are correlated through linkage disequilibrium, sequences through shared ancestry, and samples through study site, so random splits leak information between training and test sets and produce optimistic estimates; splitting by chromosome, by taxonomic clade or by cohort is more honest. Labels are often noisy or incomplete, because the training data come from databases whose content reflects what has been studied. Training sets also under-represent many populations, so a model may perform worse for groups whose data are scarce, and that disparity is invisible unless performance is reported by group. Interpretability matters when a prediction informs a decision, and attribution methods give hints about what a model uses rather than a mechanism.

Practical example

A group builds a classifier to distinguish bacterial isolates that carry a resistance determinant from those that do not. Validating on isolates from the same hospital gives excellent accuracy, but performance drops when the model is applied to isolates from another country, because the original training set captured a narrow range of lineages.

Common misunderstanding

A model with high accuracy on a test set is often assumed to be ready for use. Accuracy measured on data resembling the training set says little about new settings, and in imbalanced problems a model can score well while failing on the rare class that matters. Evaluation on genuinely independent data is the minimum requirement.
