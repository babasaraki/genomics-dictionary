De novo assembly

Bioinformatics and statistics Pathogen genomics Published

Definition

De novo assembly reconstructs a genome from sequencing reads alone, without using a reference sequence of the same organism as a guide. It is the approach taken when no suitable reference exists, when the sample may contain sequence the reference lacks, or when the aim is to describe structure rather than catalogue differences from a template.

Technical explanation

In de novo assembly, overlaps among reads are used to build a graph whose paths represent possible reconstructions of the underlying sequence. Short-read assemblers usually build de Bruijn graphs over k-mers, where the choice of k trades sensitivity in low-coverage regions against the ability to resolve repeats; long-read assemblers compare reads directly and can traverse repeats that short reads cannot. Because no reference constrains the result, the method recovers sequence genuinely absent from any reference, including plasmids, mobile elements, novel insertions and the accessory genome of bacteria, which is precisely why it is standard in pathogen genomics. The cost is higher sensitivity to input quality: uneven coverage, contamination, chimeric reads and residual adapter sequence all distort the graph, and a mixed sample may be assembled into a chimeric consensus that corresponds to no real organism. Assemblies are therefore polished, screened for contamination and assessed for completeness before use. Reference-guided assembly is a separate approach that maps reads to a related genome and will not recover novel material.

Practical example

A laboratory investigating carbapenem resistance in Escherichia coli assembles each isolate de novo rather than mapping to a reference strain. Several isolates yield small circular contigs carrying a carbapenemase gene alongside plasmid replication and transfer genes. Mapping against the chromosomal reference alone would have shown the gene present but given no information about the element carrying it.

Common misunderstanding

De novo assembly is often thought to be the more objective option because it uses no reference. It still depends heavily on choices: the assembler, the k-mer size, coverage depth and read length all shape the result, and two assemblers given identical reads routinely produce different contig sets. Reference-free is not assumption-free.
