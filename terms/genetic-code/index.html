Genetic code

Genetics foundations Published

Definition

The genetic code is the set of rules by which cells translate the sequence of bases in a messenger RNA into the sequence of amino acids in a protein. Bases are read in groups of three, and each group corresponds to one amino acid or to a stop signal. The same code is used by almost all living things, with a few known exceptions.

Technical explanation

The standard genetic code maps sixty-four triplets onto twenty amino acids plus termination. Its near-universality is strong evidence of common ancestry and is what allows a gene from one organism to be expressed in another. Exceptions exist: mitochondria in several lineages, including human mitochondria, reassign particular codons, and some ciliates and bacteria use alternative assignments, so translating a mitochondrial sequence with the standard table produces wrong protein predictions. The code is also structured rather than arbitrary, since codons differing at the third position often specify the same or chemically similar amino acids, which buffers the effect of many substitutions. Selenocysteine and pyrrolysine are incorporated at particular stop codons through specialised context-dependent mechanisms. In practice, software that translates nucleotide sequence requires the correct translation table and the correct reading frame, and specifying neither is a common source of nonsense output. The code says nothing about whether a sequence is actually transcribed or translated in a given cell.

Practical example

An analyst translating a mitochondrial gene with default software settings obtains a protein riddled with premature stops. Switching to the vertebrate mitochondrial translation table resolves the apparent nonsense, illustrating why the translation table is recorded explicitly in pipelines rather than left at whichever default a tool happens to apply.

Common misunderstanding

People often describe the genetic code as universal without qualification. Several translation tables exist, and mitochondrial and some microbial sequences follow different assignments. A second misunderstanding treats the genetic code as the whole of genetic information; it governs only the protein-coding step and says nothing about regulation, splicing or non-coding RNA function.
