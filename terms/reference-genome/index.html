Reference genome

Human and population genomics Bioinformatics and statistics Published

Definition

A reference genome is an agreed, assembled DNA sequence used as a shared coordinate system, so that laboratories everywhere can describe positions and variants in the same way. The current human reference is a mosaic built from a small number of donors. It is a convenient yardstick rather than a model of a healthy or typical person, and it does not contain all human variation.

Technical explanation

The human reference assembly supplies stable coordinates for read mapping, variant calling and annotation. Successive builds, including GRCh37, GRCh38 and the telomere-to-telomere assembly that resolved previously missing regions such as centromeric satellite arrays and acrocentric short arms, use different coordinates, so results must always be reported with their build and lifted over carefully when datasets are combined. The assembly is a haploid consensus derived from several donors, with alternate loci supplied for highly polymorphic regions such as the major histocompatibility complex. This design creates reference bias: reads carrying non-reference alleles align less readily, so variation is under-called wherever a sample's true sequence diverges from the reference, an effect distributed unevenly across populations because the donor panel was not globally representative. Graph-based and pangenome references address this by representing many haplotypes at once. Note also that the reference carries minor alleles at a considerable number of positions, so matching the reference is not a statement about health.

Practical example

A bioinformatics core receives variant calls from a collaborator in GRCh37 coordinates and must merge them with its own GRCh38 dataset. Liftover converts most positions successfully, but a subset fails or maps into a different sequence context. The core records those failures explicitly rather than dropping them silently, since unresolved regions often contain the structurally complex loci of greatest interest.

Common misunderstanding

The reference genome is widely imagined as a normal or healthy genome against which differences are faults. It is a composite coordinate framework, it carries rare and minor alleles at many sites, and it under-represents variation found in populations absent from the original donor set. Differing from the reference means being different, not being abnormal.
