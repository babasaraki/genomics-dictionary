Read

Sequencing and laboratory methods Published

Definition

A read is one stretch of sequence produced by a sequencing instrument from a single fragment of DNA or RNA. Each read is a string of bases together with a quality value for every base, indicating how confident the instrument is in that call. A sequencing run produces millions of reads, which analysis software then maps or assembles.

Technical explanation

A read is the atomic unit of sequencing output: the base calls derived from one template molecule or one cluster of identical copies, with per-base quality scores, conventionally stored in FASTQ format. Read length is set by the chemistry, from tens of bases on some short-read configurations to hundreds of kilobases on single-molecule platforms. Reads are not observations of the genome directly; they are observations of library molecules, so they inherit every bias introduced during extraction, fragmentation, enrichment and amplification. Several reads can also derive from the same original molecule after amplification, and these duplicates must be marked so that they are not counted as independent evidence for a variant. Downstream, a read acquires a mapping position and a mapping quality describing the confidence that it came from that locus, which is a separate quantity from the base quality. Reads that fail to map, map to many places, or map with low confidence are not necessarily errors; they frequently indicate repetitive sequence, contamination, or genuine divergence from the reference used.

Practical example

A bioinformatician inspects a surveillance dataset and finds that a quarter of reads in one sample fail to map to the expected pathogen reference. Classifying the unmapped reads shows them to be host sequence carried through extraction. The run itself was sound; the sample simply contained a mixture, and the effective depth on the target was lower than the raw read count implied.

Common misunderstanding

The raw number of reads is often treated as the measure of how much data a sample yielded. It is not, on its own. Reads can be duplicates of one another, can come from contaminating material, or can be unmappable. What matters is how many independent, correctly placed reads cover the region being studied.
