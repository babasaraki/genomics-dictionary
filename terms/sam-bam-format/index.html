SAM and BAM formats

Bioinformatics and statistics Published

Definition

SAM and BAM are the standard formats for storing sequencing reads after they have been mapped to a reference genome. SAM is human-readable text; BAM is the same information compressed into a binary file that software can read quickly. Each record says where a read aligned, how well it aligned, and how its bases correspond to the reference at that position.

Technical explanation

A SAM record holds the read name, a bitwise flag describing pairing and orientation, the reference name and leftmost position, a mapping quality, a CIGAR string describing the run-length pattern of matches, insertions, deletions and clipping, the mate's position, the sequence and its quality string, and optional tagged fields used by individual tools. BAM is the compressed binary equivalent; CRAM compresses further by storing differences from the reference rather than the full sequence. Sorted and indexed BAM files allow a viewer or variant caller to retrieve a single locus without scanning the file. Mapping quality is the most misread field: it estimates the probability that the read is placed at the wrong location, not that the bases are correct, and it collapses to zero where a read maps equally well to several places. Reads from repetitive regions, segmental duplications and paralogous genes therefore carry little weight, which is one reason coverage appears uneven across a genome even after a technically successful run.

Practical example

A clinical scientist reviewing a candidate variant opens the BAM file in a genome browser. The supporting reads all align in the same orientation and all carry the alternative allele at the very end of the read, next to a homopolymer run. The pattern suggests an alignment artefact rather than a true variant, so the position is checked by an independent method before it is reported.

Common misunderstanding

Mapping quality and base quality are frequently confused. A read may consist entirely of high-confidence base calls and still have a mapping quality of zero because the region it came from is repeated elsewhere in the genome. Conversely, a uniquely placed read can carry poor base qualities. The two numbers answer different questions and both matter.
