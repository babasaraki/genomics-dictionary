Phylogenetic tree

Pathogen genomics Published

Definition

A phylogenetic tree is a diagram that shows how sequences are related by descent from common ancestors. Each tip is a sampled sequence, each internal branching point is an inferred ancestor, and branch lengths usually represent the amount of genetic change or elapsed time. Trees are the main way outbreak analysts visualise which pathogen samples belong together.

Technical explanation

A phylogenetic tree is a hypothesis about the branching history of sequences, estimated from a multiple sequence alignment using distance, parsimony, maximum likelihood or Bayesian methods. Likelihood and Bayesian approaches fit an explicit model of nucleotide substitution, with parameters for base frequencies, substitution rates and among-site rate variation, and model choice measurably affects the result. Support for individual branches is assessed by bootstrap resampling or posterior probabilities, and poorly supported branches should not be interpreted. Trees are unrooted unless a root is imposed, either with an outgroup or, for time-stamped pathogen data, by fitting a molecular clock. Key limitations include sensitivity to alignment errors, to recombination, which makes a single tree an inadequate description, and to sampling, since a tree summarises only the sequences included. Scale matters too: a tree of a slowly evolving bacterium sampled over weeks may have almost no resolved structure, while a rapidly evolving RNA virus can show clear branching within an outbreak. Interpretation should always pair the topology with branch support and sampling information.

Practical example

A student analysing bacterial genomes from a single hospital builds a maximum likelihood tree and sees a striking split into two groups. Checking branch support reveals low bootstrap values on the deep branches, and the apparent split disappears when recombinant regions are removed before inference. The revised tree supports one group with a few long-branch outliers instead.

Common misunderstanding

Trees are often read as a direct record of who passed the infection to whom, with tips arranged left to right as a timeline. Neither reading is correct. The order of tips across the page is arbitrary and can be rotated at any node, and tips are sampled cases, not ancestors of each other. Only the branching pattern carries meaning.
